# Menstrual Cycle Status and the Acute Subjective Psychedelic Experience  
  
## Codebook  

| Variable | Description | Coding |
| ---------------------------------------------------- | ----------------------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| pid | Arbitrary participant identifier | P001–P169 |
| Sex_Birth_Follow | Sex assigned at birth | 0 = male, 1 = female |
| Cycle_Month_Follow | Menstruated about once per month over the past two months | 0 = no, 1 = yes |
| Cycle_Intense_Follow | Menstruating at the time of the most intense psychedelic experience | 0 = no, 1 = yes |
| Pregnant_Follow | Pregnant (reported at follow-up) | 0 = no, 1 = yes |
| Breastfeeding_Follow | Breastfeeding (reported at follow-up) | 0 = no, 1 = yes |
| *_Month_Intense_Follow | Substance used during the most intense experience | 0 = no, 1 = yes |
| Dose_Follow | Self-reported dose | 1 = low, 2 = moderate, 3 = large, 4 = very large, 5 = extremely large |
| Age_Four_Baseline | Age group | 0 = 18–24, 1 = 25–34, 2 = 35–44, 3 = 45–50 |
| EDI_Follow_1–8 | Ego Dissolution Inventory items | 0–100 |
| MEQ_Follow_1–30 | Mystical Experience Questionnaire items | 0–5 |
| CEQ_Follow_1–26 | Challenging Experience Questionnaire items | 0–5 |
| EDI_Follow_Total, MEQ_Follow_Total, CEQ_Follow_Total | Total scores (mean of items; MEQ total is the mean of all 30 items) |  |
| MEQ_*_Follow | MEQ subscale scores: Mystical, Positive mood, Transcendence, Ineffability | mean of items |
| CEQ_*_Follow | CEQ subscale scores: Fear, Grief, Physical distress, Insanity, Isolation, Death, Paranoia | mean of items |
| Any_Harm_Follow | Thoughts or attempts to harm oneself or others in the time after the experience | 0 = no, 1 = yes |
